# Maxuscore Calendar Checker

マクサスコアに登録したアポイントが、Googleカレンダーに正しく反映されているか確認するためのWebアプリです。

## MVPでできること

- マクサスコアのアポイントCSVを読み込み
- Googleカレンダーの予定CSVまたはICSを読み込み
- 複数メンバーの対応表CSVを読み込み
- 未反映、日時ズレ、担当者違い、余分な予定を検出
- 照合結果をCSVで出力

## 使い方

`index.html` をブラウザで開き、各ファイルをアップロードして `照合` を押します。

## CSV例

### マクサスコアCSV

```csv
顧客名,日付,開始時刻,終了時刻,担当者,ステータス
山田太郎,2026-05-18,10:00,11:00,佐藤,確定
```

### GoogleカレンダーCSV

```csv
タイトル,日付,開始時刻,終了時刻,担当者
山田太郎 初回商談,2026-05-18,10:00,11:00,sato@example.com
```

### メンバー対応表CSV

```csv
担当者,カレンダー
佐藤,sato@example.com
```
